# Anurag Kumar Srivastava — Portfolio

Source code for my personal portfolio website, created to present my work in Python development, data engineering, Generative AI, RAG systems, AI agents, and backend application development.

**Live portfolio:** [https://anurag-kumar-srivastava-portfolio.vercel.app/](https://anurag-kumar-srivastava-portfolio.vercel.app/)

**Live portfolio:** [velvet-ripple-tjhw.here.now](https://velvet-ripple-tjhw.here.now/)

## Technologies

- Next.js 16 with the App Router and static export
- React 19 and TypeScript
- Framer Motion for accessible interface animation
- Lucide React icons
- Tailwind CSS tooling and custom responsive CSS
- here.now static hosting

## Main features

- Responsive, accessible single-page portfolio
- Interactive project cards with source-code and live-demo links
- Animated development pipeline and section transitions
- Dedicated skills, education, certification, and contact sections
- Direct GitHub, LinkedIn, and resume access
- Reduced-motion support and keyboard-friendly interactions
- SEO metadata, sitemap, robots configuration, and custom favicon

## Run locally

Node.js 20.9 or newer is required.

```bash
git clone https://github.com/IntelliCoder-AI/my-portfolio.git
cd my-portfolio
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Validate and build

```bash
npm run typecheck
npm run build
```

The production build is exported as static files in `out/`.

## Project structure

```text
src/app/          Application routes, metadata, and global styles
src/components/   Reusable interface and interaction components
src/data/         Portfolio content, projects, skills, and profile links
public/           Resume files and static assets
scripts/          Deployment and document-generation utilities
```
